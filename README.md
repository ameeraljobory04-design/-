# الملازم

> اي ولة كلشي ملازم

تطبيق بسيط تخلي بيه كل ملازم الدراسة بمكان واحد: تقرا الصفحات مثل قارئ PDF، تتنقل بين المحاضرات، وتأشر على المحاضرة الي خلصتها.

يشتغل بالمتصفح، وينزل على الموبايل كتطبيق (PWA)، ويشتغل بدون إنترنت بعد أول فتح.

## رفعه على GitHub Pages

1. سوّي repository جديد على GitHub (مثلاً `almalazim`).
2. ارفع كل الملفات الي بهذا المجلد (مو المجلد نفسه، محتوياته) للـ repository.
   - من الموقع: **Add file ← Upload files** واسحب الملفات والمجلدات.
   - أو من الطرفية:
     ```bash
     git init
     git add .
     git commit -m "الملازم"
     git branch -M main
     git remote add origin https://github.com/USERNAME/almalazim.git
     git push -u origin main
     ```
3. روح لـ **Settings ← Pages**، وبـ **Source** اختار `Deploy from a branch`، وبعدين `main` و `/ (root)`، واضغط **Save**.
4. بعد دقيقة أو دقيقتين يصير الرابط: `https://USERNAME.github.io/almalazim/`

## تنصيبه على الموبايل

- **آيفون (Safari):** افتح الرابط ← زر المشاركة ← **Add to Home Screen**.
- **أندرويد (Chrome):** افتح الرابط ← القائمة ⋮ ← **Install app** أو **Add to Home screen**.

يطلع بأيقونة العرموطة وباسم «الملازم»، وينفتح بشاشة كاملة مثل أي تطبيق.

## إضافة ملازم جديدة

**من داخل التطبيق:** اضغط الزر الأزرق الدائري ← اختار PDF ← اكتب الاسم والمادة. الملزمة تنحفظ على نفس الجهاز بس، وما تطلع على الأجهزة الثانية.

**حتى تطلع على كل الأجهزة (الأفضل):** ضيفها للـ repository:

1. حوّل كل صفحة لصورة JPG (عرض ~1400 بكسل) وحطها بمجلد جديد داخل `pages/`، مثل `pages/networks/01.jpg`، `02.jpg`…
2. ضيف عنصر جديد بملف `books.json` بنفس شكل العناصر الموجودة:
   ```json
   {
     "id": "networks",
     "title": "Computer Networks",
     "subject": "الشبكات",
     "color": "#36b3d9",
     "order": 6,
     "pages": 20,
     "lectures": [
       { "t": "Lecture 1 — Introduction", "page": 1, "short": "L1" },
       { "t": "Lecture 2 — OSI Model", "page": 9, "short": "L2" }
     ],
     "pageImages": [
       { "src": "pages/networks/01.jpg", "w": 1400, "h": 1812 }
     ]
   }
   ```
3. ارفع التغييرات، والتطبيق يحدّث نفسه لمن ينفتح وياه إنترنت.

## وين تنحفظ البيانات؟

كلشي على جهازك، وماكو أي سيرفر:
- تأشير المحاضرات وآخر صفحة قريتها وتعديلات المحاضرات تنحفظ بالمتصفح (localStorage).
- الملازم الي تضيفها من داخل التطبيق تنحفظ بالمتصفح (IndexedDB).

إذا مسحت بيانات المتصفح، يروح التأشير والملازم المضافة يدوياً. أما الملازم الي بالـ repository فتبقى.
